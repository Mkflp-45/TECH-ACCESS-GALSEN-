POLITIQUE DE CONFIDENTIALITÉ

Dernière mise à jour : 2024

1. Introduction

TECH ACCESS respecte votre vie privée et s'engage à protéger vos données personnelles. Cette politique de confidentialité explique comment nous collectons, utilisez et protégeons vos informations.

2. Données collectées

Nous collectons les données personnelles suivantes :

  • Informations de contact : Nom, email, téléphone
  • Adresse : Adresse de livraison
  • Informations de paiement : Numéro de transaction Wave (jamais stocké en clair)
  • Historique d'achats : Produits commandés et dates
  • Données techniques : Adresse IP, navigateur, type d'appareil

3. Utilisation des données

Vos données sont utilisées pour :

  • Traiter vos commandes et effectuer les livraisons
  • Vous contacter concernant votre commande ou nos services
  • Améliorer notre site et nos services
  • Envoyer des offres promotionnelles (avec votre consentement)
  • Prévenir la fraude et les abus

4. Partage des données

  • Nous ne partageons jamais vos données avec des tiers sans votre consentement
  • Nous pouvons partager les informations nécessaires avec les livreurs pour l'expédition
  • Les données sont stockées sur des serveurs sécurisés (Firebase/Google Cloud)

5. Sécurité des données

  • Toutes les transactions sont chiffrées avec SSL/TLS
  • Les mots de passe sont hachés et ne sont jamais stockés en clair
  • Accès limité aux données personnelles
  • Audit de sécurité régulier

6. Durée de conservation

  • Données de commande : Conservées 5 ans pour les obligations fiscales
  • Données de contact : Conservées jusqu'à votre demande de suppression
  • Logs techniques : Supprimés après 90 jours

7. Vos droits

Vous avez le droit de :

  • Accéder à vos données personnelles
  • Corriger vos données
  • Supprimer vos données (droit à l'oubli)
  • Exporter vos données
  • Vous opposer au traitement de vos données

8. Cookies

  • Notre site utilise des cookies pour améliorer l'expérience utilisateur
  • Les cookies analytiques nous aident à comprendre comment vous utilisez le site
  • Vous pouvez désactiver les cookies dans les paramètres de votre navigateur
