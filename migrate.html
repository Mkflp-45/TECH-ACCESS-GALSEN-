Migration Firestore

Importer les produits locaux vers Firestore

Cette page sert de point d’entrée pour la migration des données du site statique vers Firestore. Elle évite maintenant le 404 annoncé par la documentation et les redirections.

1. Vérifier la configuration Ouvre firebase-config.js et confirme que les identifiants de projet sont corrects.
2. Préparer les règles Publie les règles Firestore du dépôt avant d’exécuter une migration en production.
3. Lancer la migration Utilise ensuite l’outil d’administration ou le script de migration prévu par le projet.
